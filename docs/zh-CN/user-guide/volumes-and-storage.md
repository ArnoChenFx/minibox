# 卷与存储

卷是存放文件的位置。卷与 Box 分离。一个 Box 使用零个或多个卷。只要卷还在，Box 停止、重建或删除后其中的文件仍会保留。

在侧栏打开 **卷** 页面查看卷和存储池。

## 卷角色

新 Box 默认获得四个卷：

| 角色 | 默认池 | 挂载于 | 模式 |
|---|---|---|---|
| **工作区** | 默认池 | `/workspace` | 读写 |
| **主目录** | 默认池 | `/home/dev` | 读写。视为敏感数据，可能存放凭据。 |
| **工具** | 默认池 | `/opt/minibox/tools` | 只读。每个池一个共享卷存放已安装工具。 |
| **缓存** | 本地池 | `/home/dev/.cache` | 读写。不包含在检查点中。 |

要使用不同卷，在创建对话框中点击 **自定义**。Box 仅挂载你列出的卷。要为已有 Box 添加卷，在其 Box 页面上挂载。

## 存储池

存储池是 MiniBox 创建卷的位置。有三种：

- **本地**池：卷在 Docker 宿主机磁盘上。该池始终存在，且为 cache 的默认池。
- **NFS** 池：卷在 NFS 服务器（例如 NAS）上。参见 [NFS 与 NAS 存储](nfs.md)。
- **路径**池：卷在你自行挂载到宿主机的文件夹中。

要添加 NFS 池，点击 **添加 NFS**。要添加路径池，点击 **添加路径**。点击 **保存存储池** 保存更改。

池表格对可用池显示 **可达**，对不可用池显示 **存储不可达**。还会显示剩余空间。

其中一个池为默认池。要更改默认池，在池对话框中点击 **设为默认池**，或在其行上使用 **默认** 设置。

仍包含卷的存储池无法移除。

## 创建与挂载卷

- 要创建卷，点击 **创建卷** 并选择存储池。该卷是独立的，即不绑定到某个 Box。
- 要将卷挂载到 Box，打开 Box 页面，使用 **挂载**。挂载卷会重建 Box，因此 MiniBox 会先显示预览。
- 要卸载卷，点击 **卸载**。卸载也会重建 Box。

更改 Box 的挂载会重建它。Box 保留名称和卷。可写层和运行中的进程会丢失。

## 读写与只读

- **读写**挂载允许 Box 修改文件。
- **只读**挂载仅允许 Box 读取文件。

同一卷可被多个 Box 挂载。在第二个 Box 中以读写方式挂载卷时，控制台会要求确认。Docker 不会在 Box 之间锁定文件，因此两个 Box 写入同一文件可能互相覆盖。

## 删除卷

在卷上点击 **删除**。MiniBox 不会删除仍被 Box 挂载的卷。

删除 Box 时，你也可以删除该 Box 拥有的卷。参见 [删除 Box](boxes.md#删除-box)。

## 卷中的文件

即使没有任何 Box 在使用，你也可以用命令行工具读写卷中的文件：

```bash
minibox files ls my-volume --path /
minibox files read my-volume notes.txt
minibox files write my-volume notes.txt --content "hello"
```

全部 `minibox files` 命令见 [CLI 参考（英文）](../../reference/cli.md)。要在 Box 页面上浏览、上传与下载文件，参见[文件](files.md)。
