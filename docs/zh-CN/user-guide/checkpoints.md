# 检查点

检查点是 Box 数据的副本。你可以从检查点派生新 Box，或将 Box 回滚到某个检查点。

检查点包含 Box 的 `/workspace` 文件夹和 home 文件夹。模板只包含系统文件，因此检查点是保存工作的方式。

检查点可在控制台中使用，也可通过 [REST API（英文）](../../reference/api.md) 使用。命令行工具不管理检查点。

检查点不是整台服务器的备份。它们与 Box 存放在同一宿主机上。对不能丢失的数据请保留宿主机外的副本。

## 创建检查点

1. 打开 Box，点击**检查点**标签页。
2. 点击**创建检查点**。
3. 在**标签**中输入短名称。留空则使用 Box 名称。
4. 在**一致性**下，选择复制文件时如何对待 Box：

   | 选项 | 行为 |
   |---|---|
   | **运行中** | Box 继续运行时进行复制。这是最快的方式。复制结果为崩溃一致。 |
   | **暂停** | 复制期间暂停运行中的 Box，然后恢复。复制期间文件不会变化。 |
   | **停止** | 复制期间停止 Box，然后再次启动。 |

   已停止或休眠的 Box 无论选哪项，都按当前状态复制。

5. 若要包含系统层，勾选**包含系统层**。这会保存 Box 已安装的软件，派生时会带上它们。耗时更长，占用更多空间。
6. 点击**创建检查点**。

检查点就绪后会出现在列表中。在**任务**面板中查看进度。

## 检查点列表

列表显示每个检查点的**拍摄时间**、**标签**、**类型**和**内容**。类型包括：

- **手动**：你拍摄的检查点。
- **自动**：MiniBox 拍摄的检查点。MiniBox 在每次回滚前会拍摄一个。
- **置顶**：你置顶的检查点。
- **旧版快照**：检查点功能出现之前的快照。可以派生或删除，但不能回滚到它。

## 派生检查点

派生会从检查点创建新 Box。来源 Box 不会改变。

1. 在该检查点行点击**派生**。
2. 在**新 Box 名称**中输入新 Box 的名称。
3. 若要复制 home 文件夹，勾选**复制 home**。默认关闭，因为 home 文件夹可能包含凭据等敏感文件。
4. 点击**派生**。

## 回滚到检查点

回滚会用检查点中的数据替换 Box 的当前数据。

1. 在该检查点行点击**回滚**。
2. 阅读对话框。其中列出**将被替换的卷**、**保持不变**和**将丢失**（容器中已更改的文件）。
3. 点击**回滚**。

在有任何更改之前，MiniBox 会为当前数据拍摄一个安全检查点。然后 Box 会用恢复的数据重建。

回滚后旧卷会保留，以便你决定如何处理。**检查点**标签页会显示**旧卷仍保留**，并提供两个按钮：

- **确认并清理**会删除旧卷。
- **撤销回滚**会再次挂载旧卷。回滚之后写入的内容都会丢失。

## 置顶与删除

- 点击**置顶**可保留检查点，即使自动清理运行也不会删除。点击**取消置顶**可再次允许清理。
- 点击**删除**可移除检查点。数据会从仓库中删除，且无法恢复。置顶的检查点须先取消置顶才能删除。

## 检查点保留多久

- 手动和置顶的检查点会保留，直到你删除它们。
- 每个 Box 会保留自动检查点。MiniBox 保留最新的 20 个，并删除超过 30 天的旧检查点。管理员可以更改这些限制。见 [配置（英文）](../../reference/configuration.md)。
- 管理员也可为所有检查点设置大小上限。达到上限时，MiniBox 不会拍摄新的自动检查点。出于同样原因，回滚也会被拒绝，因为回滚会先拍摄安全检查点。
