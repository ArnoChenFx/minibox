# 宿主机

宿主机是 MiniBox 可以在其上运行 Box 的 Docker 引擎。运行 MiniBox 的机器始终是宿主机 **local**。你可以添加其他 Docker 引擎，并在创建 Box 时选择宿主机。

每个 Box 都会记录其宿主机。你对 Box 做的所有操作都在该宿主机上执行。

## 连接宿主机的方式

| 端点 | MiniBox 如何连接 | 你需要准备的内容 |
|---|---|---|
| `unix:///var/run/docker.sock` | 本机上的套接字，或挂载进容器的套接字 | 无其他要求 |
| `tcp://host:2376` | 引擎的 TLS 端口，双向 mutual TLS | 为引擎证书签名的 CA，以及引擎信任的客户端证书与私钥。 |
| `ssh://user@host` | 经 SSH 转发的引擎 Docker 套接字。只需开放 SSH 端口。 | 能以该用户登录的 SSH 密钥。套接字为 `/var/run/docker.sock`，除非路径另有说明。 |

## 添加宿主机

1. 在侧栏点击 **设置**，然后打开 **宿主机** 部分。
2. 点击 **添加宿主机**。
3. 填写表单：
   - **标识**：小写字母、数字和连字符，以字母开头。
   - **名称**：便于你识别的名称。
   - **端点**：上表中的一种形式。
   - 端点所需的凭据字段：`tcp://` 需要 **CA 证书（PEM）**、**客户端证书（PEM）** 和 **客户端私钥（PEM）**；`ssh://` 需要 **SSH 私钥（OpenSSH 格式，无口令）**。
4. 先点击 **测试连接**。MiniBox 会连接引擎，读取其版本与容量并显示结果。不会保存任何内容。
5. 点击 **添加宿主机**。

对于 SSH 宿主机，MiniBox 会显示以 `SHA256:` 开头的宿主机密钥指纹。请与机器上的密钥核对，然后点击 **信任并添加**。仅在指纹一致时才添加该宿主机。

凭据保存在 MiniBox 宿主机上，控制台不会再次显示它们。

## 在其他宿主机上创建 Box

在创建对话框中选择 **宿主机**。默认为 **local**。

在其他宿主机上的 Box 需要该宿主机 Docker 引擎上已有其模板镜像。请先在目标引擎上构建或复制模板。模板不会在宿主机之间复制。

## 查看宿主机

**设置** 页面会列出每个宿主机及其 **状态**、**容量** 和上面的 **Box** 数量。当有多个宿主机时：

- 每个 Box 会标明其宿主机。
- 概览页会为每个宿主机显示一张卡片。
- 顶栏可以按宿主机筛选列表。
- 离线的宿主机上的 Box 会显示为不可达，列表其余部分仍会加载。

## 移除宿主机

点击该宿主机旁的 **移除** 并确认。仍持有 Box、卷或检查点的宿主机无法移除。**local** 宿主机无法移除。

## 限制

- 远程宿主机上的 Box 不支持端口预览。见 [端口预览](port-preview.md)。
- 每个宿主机各自保留检查点。检查点不会在宿主机之间复制。见 [检查点](checkpoints.md)。
- 宿主机级别的 CPU 与内存占用仅对本机宿主机显示。远程宿主机显示其引擎上报的核心数与内存。
- 命令行工具没有宿主机相关命令。请使用控制台，或 [REST API（英文）](../../reference/api.md)。
- [Agent 令牌](access-and-tokens.md) 可以限制为特定宿主机。
