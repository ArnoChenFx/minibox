# 设置

在侧栏打开 **设置** 以管理控制台与服务器的访问。页面左侧的菜单列出各部分，每次只显示一个部分。每个部分都有自己的地址（如 `#/settings/hosts`），浏览器的前进与后退按钮可在它们之间切换。该页面包含以下部分：

| 部分 | 用途 |
|---|---|
| **运行配置** | 查看监听地址、Docker 套接字、Box 上限及相关服务器设置。这些值在此为只读。 |
| **端口预览** | 设置了 `PREVIEW_BASE_DOMAIN` 时，显示子域名预览的配置，并从 MiniBox 主机运行检查。路径模式没有需要检查的内容。见 [子域名预览](../admin/preview-subdomains.md)。 |
| **宿主机** | 添加 Agent 宿主机或 Docker 宿主机，测试 Docker 宿主机，以及移除宿主机。移除 Agent 宿主机时会先吊销其 Agent。见 [宿主机](hosts.md)。 |
| **外观** | 在浅色与深色之间切换。若未保存选择，主题跟随系统。手动选择会在该浏览器中记住。 |
| **登录会话** | 查看已登录的浏览器并使其退出。见 [访问、会话与令牌](access-and-tokens.md)。 |
| **Agent API 令牌** | 创建、查看并吊销供 Agent 与脚本使用的令牌。见 [访问、会话与令牌](access-and-tokens.md#agent-api-令牌)。 |
| **密钥** | 添加、替换和删除密钥。见 [环境变量与密钥](environment-and-secrets.md)。 |
| **SSH 公钥** | 添加和删除可经直连 SSH 登录的公钥。每个公钥显示标签、指纹、添加时间与最近使用时间。见 [SSH 访问](ssh-and-cli.md#用任意-ssh-客户端直连)。 |
| **异地目标** | 添加用于检查点包和备份的 S3 兼容或 SFTP 目标，检查并移除它们。见[备份](../admin/backups.md#异地目标)。 |
| **备份** | 设置、修改与关闭备份计划，查看下次与上次运行。设置之前为关闭状态。见[计划备份](../admin/backups.md#计划备份)。 |
| **通知** | 添加、修改、暂停与删除通知渠道，发送测试通知，并查看最近的发送记录。仅所有者可用。见 [通知](notifications.md)。 |

**关于** 页面显示当前运行的 MiniBox 版本，并提供文档、变更日志与许可证的链接。点击侧栏底部的版本号即可打开它。

手机上侧栏是一个抽屉，由底部标签栏的 **更多** 打开；标签栏另外三项直接打开 **概览**、**Box** 与 **活动**。打开这类独立页面（例如本页）时，标签栏高亮的是 **更多**。

在 **设置** 页面上所做的更改立即生效。密钥与令牌仅在创建时显示一次。
