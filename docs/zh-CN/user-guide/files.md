# 文件

Box 页面上的 **文件** 标签页浏览 Box 卷中的文件：工作区、主目录，以及 Box 挂载的其他卷。Box 停止时该标签页同样可用，因为 MiniBox 通过短暂运行的辅助容器直接读写卷。[卷与存储](volumes-and-storage.md) 介绍了卷。

此标签页只显示卷中的文件。Box 在卷之外写入的文件（例如用 `apt install` 安装的包）不会列出。要处理这些文件，请使用[终端](terminal-and-sessions.md)。

## 浏览

- 打开 Box，点击 **文件**。
- 用 **卷** 选择器选择卷。每个选项显示其挂载路径和角色；挂载为只读时显示 **只读**。Box 有工作区卷时，标签页默认打开 `/workspace`。
- 点击文件夹即可打开。列表上方的面包屑显示当前位置，点击路径中的任一部分即可返回该位置。
- 点击列标题可按 **名称**、**大小** 或 **修改时间** 排序。文件夹始终排在前面。再次点击同一列标题可反转顺序。
- 在 **筛选文件** 中输入文字，只显示名称包含该文字的条目。筛选不区分大小写。
- 以点开头的名称默认隐藏。开启 **显示隐藏文件** 即可显示。该设置不会保存，下次打开页面时恢复为关闭。
- 一个文件夹最多列出 2,000 个条目。条目超过时，列表会提示部分条目未显示。打开子文件夹即可查看其余条目。

## 预览与下载

- 点击文件名或眼睛图标即可预览。预览显示最多 256 KiB 文件开头的部分，以文本形式展示。不是 UTF-8 文本的文件无法预览，请改为下载。
- 点击文件的下载图标，按原样下载该文件。
- 点击文件夹的下载图标，下载为 `<名称>.tar.gz`。
- 符号链接显示为链接，不会被跟随，因此无法在此打开或下载其指向的目标。

## 上传

- 将文件或文件夹拖到文件面板上，或点击 **上传文件** 或 **上传文件夹**。文件夹会连同其中的全部内容一起上传。
- 文件会逐个上传到当前所在的文件夹。进度条显示已完成的文件数和已发送的字节数。点击 **取消上传** 即可停止；取消前已完成的文件保留在原处。
- 如果文件夹中已有同名文件，MiniBox 会在发送任何内容之前列出这些名称，并只询问一次。点击 **替换** 覆盖这些文件，点击 **跳过这些文件** 只上传新文件，或点击 **取消** 放弃本次上传。
- 超过 `FILE_UPLOAD_MAX_MB` 的文件会被拒绝，提示信息中会给出上限。默认为 1024 MB。参见[配置（英文）](../../reference/configuration.md)。
- 上传的文件和文件夹归 Box 的 `dev` 用户所有，即 uid 1000。

## 新建、重命名与删除

- **新建文件夹** 在当前文件夹中创建新文件夹。
- **重命名** 就地修改文件或文件夹的名称。名称不能是 `.` 或 `..`，不能包含 `/` 或控制字符，最长 255 字节。
- **删除** 会先要求确认。对话框会说明该条目是文件还是文件夹。文件夹会连同其中的全部内容一起删除，且删除无法撤销。卷的根目录不能在此删除。要移除整个卷，参见[删除卷](volumes-and-storage.md#删除卷)。

## 路径与安全

- 路径相对于卷的根目录。通过 `..` 越出卷的路径会被拒绝。
- 指向卷内的符号链接会被跟随。指向卷外的符号链接会被拒绝。
- 每次上传都先写入临时名称，再移动到目标位置。上传失败不会在最终名称下留下不完整的文件。

## 命令行与 API

同样的操作也可以在终端中完成，无论 Box 是否在运行：

```bash
minibox upload ./site mybox:/workspace/
minibox download mybox:/workspace/report.txt
minibox cp mybox:/workspace/report.txt ./report.txt
```

加上 `--overwrite` 可替换已有文件。参见 [CLI 参考（英文）](../../reference/cli.md#copy-files-to-and-from-a-box) 中的复制文件说明，以及 [REST API 参考（英文）](../../reference/api.md#files) 中的文件端点。

## 限制

| 限制 | 取值 | 设置 |
|---|---|---|
| 上传大小 | 默认 1024 MB | `FILE_UPLOAD_MAX_MB` |
| 文本预览 | 256 KiB | 固定 |
| 单个文件夹的条目数 | 2,000 | 固定 |
