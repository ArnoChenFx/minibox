# 访问、会话与令牌

MiniBox 有三种方式证明你的身份：

- **访问密钥**用于登录控制台，也是 REST API、CLI 和 MCP 的所有者密钥。
- **浏览器会话**是你在每个浏览器中保持的登录状态。
- **Agent 令牌**供 Agent 和脚本使用的密钥。每个令牌只有你授予的权限。

## 访问密钥

访问密钥是一串 64 个字符的随机字符串。除非管理员已设置，MiniBox 会在首次启动时创建它。要从 Docker 安装中读取，请运行：

```bash
docker exec minibox cat /data/access_key
```

请像 root 密码一样保管访问密钥。拥有该密钥的人可以控制整台服务器。不要把它放进提示词、日志或代码仓库。应给 Agent 使用 Agent 令牌。

如果你怀疑密钥已泄露，请让管理员更换它。更换密钥会结束所有浏览器登录。

多次失败后，错误的密钥会被拒绝一段时间。正确的密钥始终可用。

## 已登录的浏览器

每个登录的浏览器对应一个会话。会话默认从登录起持续 30 天。管理员可以更改此设置。

要查看已登录的浏览器，请打开**设置**。在**登录会话**下，列表显示每个浏览器、登录时间以及最近活动时间。**当前浏览器**标记你正在使用的那个。

- 要退出某个浏览器，点击它旁边的**撤销**，并确认。该浏览器中打开的终端会关闭。
- 要退出所有其他浏览器，点击**退出其他会话**，并确认。

## Agent API 令牌

Agent API 令牌是以 `mbx_` 开头的密钥。每个 Agent 或脚本使用一枚。它只能在其 scope 和配额允许范围内操作。

### 创建令牌

1. 打开**设置**，在 **Agent API 令牌**中点击**新建令牌**。
2. 输入名称，并选择**预设**。见下表。
3. 若令牌应过期，设置**有效期（天）**。留空表示不过期。
4. 选择该令牌可使用的 **Box**、**卷**和**宿主机**。
5. 在**配额**下，可按需设置限制。限制包括 Box 数量、CPU 核数合计、内存合计（MB）、最长 TTL（小时）、每分钟请求数，以及检查点数量。
6. 点击**新建令牌**。请立即复制密钥。MiniBox 不会再次显示。

创建令牌后，MiniBox 会显示 **REST** 和 **MCP 客户端配置**的示例，并已填入密钥。复制其中任意一种即可。

### 预设

| 预设 | 允许的操作 |
|---|---|
| `readonly` | 在本宿主机上读取 Box 和文件。默认只能看到它创建的 Box，且不能创建 Box。指定具体 Box 或全部 Box 后才有用。 |
| `operator` | 除使用密钥外的一切操作，仅限本宿主机。仅限该令牌创建的 Box。 |
| `sandboxed-agent` | 类似 `operator`，但不能挂载已有卷、安装工具或使用 SSH。适用配额：5 个 Box、合计 8 核 CPU 和 16 GB 内存、4 小时 TTL、每分钟 60 次请求、20 个手动检查点。 |
| `admin` | 全部 scope，全部 Box 和全部宿主机。仅用于可信工具。 |

### scope

每个预设由以下 scope 组成：

| scope | 允许的操作 |
|---|---|
| `box:read` | 查看 Box 及其详情、模板、任务，以及可见 Box 的事件 |
| `box:write` | 创建和修改 Box |
| `box:delete` | 删除 Box |
| `exec` | 在 Box 中运行命令。命令可读写该 Box 挂载的每个卷。 |
| `box:ssh` | 打开到 Box 的 SSH 连接 |
| `files:read`, `files:write` | 读写卷中的文件 |
| `port:expose` | 预览端口，以及通过 SSH 转发端口 |
| `checkpoint:create` | 创建检查点和快照，并修改或删除该令牌创建的检查点 |
| `checkpoint:restore` | 将 Box 回滚到某个检查点 |
| `volume:read` | 查看卷 |
| `volume:write` | 创建卷 |
| `volume:attach` | 将已有卷挂载到 Box |
| `tool:install` | 安装、升级和卸载工具；把 Box 存为模板、删除模板 |
| `secret:use` | 让 Box 引用密钥，包括代码仓库克隆使用的密钥 |

只有所有者可以创建、修改或吊销令牌。令牌不能创建其他令牌。构建或重新构建模板、拉取镜像只限所有者，任何 scope 都不能允许。

### 吊销令牌

点击令牌上的**吊销**，并确认。使用该令牌的脚本会立即停止。使用它的已打开终端或事件流也会关闭。

若要同时删除该令牌创建的 Box，请勾选**同时删除此令牌创建的 Box**。它们的工作区卷也会被删除。
