# 环境变量与密钥

环境变量是 Box 内程序启动时读取的设置，例如 `NODE_ENV` 或 API URL。密钥是 MiniBox 保存在宿主机上的值，传给 Box 时不会再次显示。

## 为 Box 设置变量

你可以在创建 Box 时设置变量，或稍后在 Box 的**设置**标签页中、**环境变量**一组设置。

- 在创建对话框中，打开**环境变量**。该部分默认折叠。
- 在 Box 的**设置**中，**环境变量**一组列出 Box 的变量。在那里编辑，并点击**保存**。

每行有名称和值。普通值在 Box 详情中会掩码显示，直到你选择**显示值**。

在**设置**中保存会重建 Box，因此可写层和运行中的进程会丢失。MiniBox 会先显示预览，并要求你确认。

## 使用密钥

密钥只需保存一次，之后任何 Box 都可以按名称引用。

1. 在侧栏点击**设置**。
2. 在**密钥**部分，点击**添加密钥**。
3. 在**名称**中输入名称，例如 `OPENAI_API_KEY`。只能使用字母、数字、点、下划线和连字符。
4. 在**值**中粘贴密钥。MiniBox 会保存它，且不会再次显示。
5. 点击**保存密钥**。

在 Box 的环境变量列表中，密钥显示为带锁的名称，例如 `🔒 secret: OPENAI_API_KEY`。Box 在创建或重建时获得该值。

要更改密钥的值，点击旁边的**替换**。新值在 Box 下次重建或创建时生效，而不是在 Box 启动时。

要删除密钥，点击**删除**。若有 Box 使用该密钥，MiniBox 会列出这些 Box。点击**仍然删除**可强制删除。这些 Box 在你再次添加该密钥之前无法重建或启动。

## 密钥规则

- **缺少密钥会阻止 Box 被创建、重建或启动。** MiniBox 不会用空值启动 Box。
- **快照、模板和带系统层的检查点拒绝密钥。** 将持有密钥的 Box 存为模板会失败。请先从 Box 中移除该密钥。
- **只有所有者和带有 `secret:use` scope 的令牌可以引用密钥。** 只有 `admin` 预设带有该 scope。创建 Box 时克隆代码仓库并指定密钥，同样需要这一权限。
- **能在 Box 中运行命令的任何人都可以读取其环境。** 这包括 `exec`、SSH 和终端。只应对应持有密钥的 Box 授予这些权限。
- **不要把密钥写进启动命令。** 命令运行时，其文本在 `ps` 中可见。请把该值作为变量或密钥提供给 Box，并从环境中读取。见[启动命令](boxes.md#启动命令)。
- **密钥值从不出现在事件、审计日志或服务器日志中。** 日志中只显示名称。
- **以 `target.` 开头的名称是保留的。** 它们保存[异地目标](../admin/backups.md#异地目标)的凭据。这些名称不会出现在密钥列表中，Box 也不能使用它们。

## 限制

- 一个 Box 最多 64 个环境变量。
- 变量名以字母或下划线开头，后续为字母、数字或下划线，最长 128 个字符。
- 普通值最长 8192 个字符，不能包含控制字符。
- 密钥值长度为 1 到 8192 个字符，不能包含换行或其他控制字符。
