# 空闲休眠与 TTL

Box 可以在一段时间无人使用时自行停止。这称为休眠。休眠中的 Box 会保留其文件，在你再次使用时重新启动。Box 也可以设置 TTL，即生存时间。TTL 结束时，MiniBox 会停止该 Box。

## 空闲休眠

- 管理员通过 `BOX_IDLE_TIMEOUT_SEC` 设置默认空闲超时。默认值为 `0`，表示关闭空闲休眠。
- 每个 Box 可以使用默认超时，或单独设置。Box 的 **概览** 选项卡会显示其 **空闲超时**：**跟随全局默认**、**永不休眠**，或该 Box 自己的秒数。
- 当以下全部为真时，Box 会休眠：
  - 没有人在使用它。
  - 在至少达到超时时间的时间内无人使用。
  - 其近期 CPU 占用低于管理员通过 `BOX_IDLE_CPU_PERCENT` 设置的阈值。

### 什么算使用

以下情况会保持 Box 唤醒：

- 打开的浏览器终端，无论是你打开的还是有人从 MiniBox 外部 attach 到会话。
- 打开的 SSH 连接。经其输入也算使用。
- 正在运行 `exec` 的命令。
- 你启动、读取或向其发送输入的会话。
- 正在加载的端口预览，或已打开的预览 WebSocket。
- 针对 Box 所挂载卷的、进行中的文件请求。
- 为该 Box 运行中的任务，例如检查点。

查看 Box 不算使用。读取其详情、统计或日志不会使其保持唤醒。

没有客户端 attach 的会话不会使其 Box 保持唤醒。若有人在无人查看的会话中运行后台作业，Box 休眠时该作业会结束。请将长作业作为后台 `exec` 运行，或保持终端打开。

### 唤醒 Box

- `exec` 会启动已停止的 Box。
- SSH 连接会启动已停止的 Box。
- 启动会话会启动已停止的 Box。
- 打开终端会唤醒处于休眠的 Box。你手动停止的 Box 不会因终端而唤醒。终端会提示 Box 未在运行，并提供启动 Box 的选项。
- 端口预览会唤醒处于休眠的 Box，但不会唤醒你手动停止的 Box。
- 读取、向会话发送内容、关闭或列出会话不会唤醒 Box。
- 读取或修改卷中的文件永远不会启动 Box。

## TTL

TTL 是从 Box 创建时开始计时的生存时间。TTL 结束时，MiniBox 会停止 Box 但不会删除它。Box 的状态随后显示 **TTL 已到期**。

TTL 已结束的 Box 不会再次启动。在清除 TTL 或将其设为更晚的时间之前，启动、重启、重建、运行命令以及打开终端或预览都会失败。清除 TTL 或设为更晚的时间后，再启动 Box。

创建对话框没有 TTL 字段。控制台会显示每个 Box 的 TTL 与空闲超时，但不会修改它们。请通过 [REST API（英文）](../../reference/api.md) 设置。

## 状态标签

| 标签 | 含义 |
|---|---|
| **休眠中** | Box 因空闲而停止。 |
| **TTL 已到期** | Box 的 TTL 已结束。 |

Box 页面还会显示 Box 的最近活动时间。
