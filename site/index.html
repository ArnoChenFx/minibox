  -p 127.0.0.1:3920:3920 \

  ghcr.io/arnochenfx/minibox:latest

docker exec minibox cat /data/access_key
Open 127.0.0.1:3920 and sign in with your access key

A few things to know

Where does MiniBox run?

On your own Linux machine with Docker. Add remote hosts when you need more capacity. MiniBox is open source under Apache-2.0, with no platform account or subscription.

Can I run untrusted code in a box?

Boxes use Docker container isolation and share the host kernel. MiniBox is designed for a trusted owner and their agents. Use stronger isolation for untrusted third-party workloads.

What happens to my work when a box changes?

Workspace and home data live in persistent volumes across rebuilds. Checkpoints let you duplicate or roll back your work. Keep exported checkpoints and server backups off the host for recovery.

How do my agents connect?

Use MCP, the CLI, SSH or the REST API. Give each agent a scoped token instead of the owner access key. You can also open a terminal in the browser and work alongside it.
