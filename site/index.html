Linux + DockerBun ≥ 1.4.3
Start from source
git clone https://github.com/ArnoChenFx/minibox.git
cd minibox
bun install --frozen-lockfile
bun run build:template
bun start
Then open 127.0.0.1:3920 on your machine.

Sign in with the generated key in data/access_key. For remote access, use HTTPS or a private network.

Before you move in.

Is MiniBox a hosted service?

MiniBox runs on your own machine. It's open source under the MIT license, with no MiniBox account or platform subscription. You provide the hardware and any paid AI provider credentials your agents need.

Can I run untrusted code in a box?

Boxes use Docker container isolation and share the host kernel. They're intended for your own agents, not as a security boundary for untrusted third-party code. Choose stronger isolation when your workload requires it.

What happens to my files when a box goes away?

Workspace and home data live in volumes, separate from a container's writable layer. When deleting a box, choose which owned volumes to keep. System snapshots exclude mounted volumes; checkpoints can preserve workspace and home data.

Does it work with my AI agent?

Any client that supports Streamable HTTP MCP can connect to MiniBox. The CLI and REST API offer another route, and the tools catalog can install supported agent CLIs inside boxes. Give agents scoped tokens rather than your owner key.
